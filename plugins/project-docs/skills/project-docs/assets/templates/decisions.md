# Decision log

Each entry records what was decided, why, and by whom.

- **Source "project lead"** (or a name): decided directly by a person.
- **Source "proposed by Claude"**: proposed during development and accepted, or not challenged.

Statuses: **Active**, **Proposed** (awaiting confirmation), **Superseded by `DEC-NNN`**, **Withdrawn**.
