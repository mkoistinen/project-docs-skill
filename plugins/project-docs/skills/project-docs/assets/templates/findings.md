# Findings

Facts we have established about the system, its dependencies, the data, and the tooling. Each entry says how sure we are and where the evidence came from.

Confidence levels:

- **Verified:** observed directly, or read in the source code.
- **Observed once:** seen in a single run; worth re-checking.
- **Inferred:** a reasonable conclusion that has not been tested directly.
